# 📚 ReadEra Smart E-Book Library Organizer 2.0

نظام أتمتة شامل ومتكامل لإدارة وتخصيص مكتبات الكتب الرقمية (PDF / EPUB)، مخصص للتزامن الفوري مع تطبيقات القراءة مثل ReadEra وأنظمة إدارة المعرفة مثل Obsidian ومع متصفحات الويب.

---

## 🌟 الميزات الرئيسية 2.0

- 📖 **تصدير الملاحظات لـ Obsidian (`export_reading_notes.py`):**
  - تحويل واستخراج اقتباسات وتظليلات وملاحظات القراءة من تطبيق ReadEra وتوليد بطاقات معرفية بتنسيق **Obsidian Markdown** منظمة ومفهرسة تلقائياً.

- ⭐ **نظام التقييم بالنجوم والمراجعات الشخصية:**
  - واجهة تقييم بصرية (1 إلى 5 نجوم ⭐) وكتابة مراجعة وانطباعات شخصية لكل كتاب داخل لوحة التحكم `index.html`.
  - مزامنة محلية وتصدير كامل المراجعات والتقييمات بنقرة واحدة في ملف `my_reviews.json`.

- 👤 **معرض المؤلفين والسلاسل (Authors Gallery):**
  - تبويب خاص يعرض بطاقات إحصائية لكل مؤلف، تبيّن عدد كتبه، نسبة القراءة المكتملة لديه، وتتيح تصفية كتب الكاتب بنقرة واحدة.

- 🤖 **التلخيص الذكي للكتب بالذكاء الاصطناعي (`ai_summarize_book.py`):**
  - استخلاص الفهرس والمقدمة واستنباط **أهم 5 أفكار رئيسية (Key Takeaways)** وعرضها في نافذة تفاعلية عند الاستعراض.

- ⚡ **محرك بحث فائق السرعة (`FlexSearch.js`):**
  - دمج محرك البحث FlexSearch في `index.html` للبحث الفوري اللحظي في العناوين، المؤلفين، الأقسام، المراجعات والوسوم.

- 🧹 **تفادي المكررات وتنظيف الأسماء (`deduplicate_books.py` & `clean_filenames.py`):**
  - مطابقة المحتوى بتوقيع SHA-256 وحذف 485 ملفاً مكرراً وتوفير 3.68 جيجابايت.
  - نظام التراجع الآمن (`--revert`) عبر `rename_rollback.json`.

- 🌐 **لوحة تحكم تفاعلية متقدمة (`index.html` Dashboard):**
  - إحصائيات بصرية، تتبع حالة القراءة (`لم يبدأ 📥` | `قيد القراءة 📖` | `تمت القراءة ✅`)، وفلاتر فورية.

- 🔄 **تزامن تلقائي مع الهاتف:**
  - دليل إعداد عملي باللغة العربية (`SYNCTHING_GUIDE.md`) لربط المكتبة بتطبيق **ReadEra** عبر **Syncthing**.

## 🚀 طريقة الاستخدام

### 1. تصدير ملاحظات القراءة إلى Obsidian
```bash
python3 export_reading_notes.py
```

### 2. توليد التلخيصات الذكية للكتب
```bash
python3 ai_summarize_book.py
```

### 3. إزالة الكتب المكررة وتنظيف الأسماء
```bash
# إزالة التكرارات
python3 deduplicate_books.py --commit

# تنظيف أسماء الكتب
python3 clean_filenames.py --commit
```

### 4. تحديث الفهرس ولوحة التحكم
```bash
python3 generate_catalog.py
```

## 🛠️ أدوات المشروع

- `export_reading_notes.py`: سكربت تحويل وتصدير ملاحظات واقتباسات ReadEra إلى Obsidian.
- `ai_summarize_book.py`: سكربت استخلاص الأفكار الرئيسية والتلخيص الذكي للكتب.
- `deduplicate_books.py`: سكربت فحص وإزالة النسخ المكررة بمطابقة المحتوى.
- `clean_filenames.py`: سكربت تنظيف وتعديل أسماء الملفات.
- `organize_subcategories.py`: سكربت التقسيم المتقدم للأقسام الضخمة.
- `generate_catalog.py`: مولد البيانات والوسوم والفهارس ولوحة التحكم.
- `index.html`: لوحة التحكم والتحليلات التفاعلية 2.0.
- `SYNCTHING_GUIDE.md`: دليل التزامن التلقائي مع الهاتف.
