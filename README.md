# 📚 ReadEra Smart E-Book Library Organizer

نظام ذكي ومأتمت لإدارة وتخصيص مكتبات الكتب الرقمية (PDF / EPUB)، مخصص للتزامن مع تطبيقات القراءة مثل ReadEra وأنظمة إدارة المعرفة مثل Obsidian.

---

## 🌟 الميزات الرئيسية

- 🧹 **تنظيف تلقائي لأسماء الكتب (`clean_filenames.py`):**
  - إزالة الأرقام التسلسلية الزائدة، والروابط الإعلانية، والرموز المعقدة.
  - حماية الأرقام الأساسية ومعالجة التعارض في الأسماء تلقائياً.
  - **نظام التراجع الآمن (`--revert`):** إمكانية استعادة الأسماء القديمة في أي وقت بنقرة واحدة.

- 📊 **فهرسة آلية شاملاً (`generate_catalog.py`):**
  - توليد ملف `library_catalog.md` محيّن تلقائياً.
  - حساب إحصائيات المكتبة (عدد الكتب، الحجم الإجمالي، الأقسام).
  - جداول تفاعلية مع روابط مباشرة لفتح الكتب بصيغة Markdown.

## 🚀 طريقة الاستخدام

### 1. تنظيف أسماء الكتب:
```bash
# معاينة التعديلات بدون تطبيق (Dry Run)
python3 clean_filenames.py

# تطبيق تنظيف الأسماء فعلياً
python3 clean_filenames.py --commit

# التراجع عن التعديلات الأخيرة وإعادة الأسماء القديمة
python3 clean_filenames.py --revert
```

### 2. تحديث الفهرس التفاعلي:
```bash
python3 generate_catalog.py
```
