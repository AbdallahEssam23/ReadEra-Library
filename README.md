# 📚 ReadEra Smart E-Book Library Organizer

نظام أتمتة شامل ومتكامل لإدارة وتخصيص مكتبات الكتب الرقمية (PDF / EPUB)، مخصص للتزامن الفوري مع تطبيقات القراءة مثل ReadEra وأنظمة إدارة المعرفة مثل Obsidian ومع متصفحات الويب.

---

## 🌟 الميزات الرئيسية

- 🧹 **تنظيف وتفادي النسخ المكررة (`deduplicate_books.py` & `clean_filenames.py`):**
  - فحص كامل للمحتوى بالتوقيع الرقمي (SHA-256) وتحديد وحذف الملفات المكررة مع الإبقاء على النسخة الأفضل من حيث الاسم والمسار.
  - إزالة الروابط الإعلانية، والرموز المعقدة مع معالجة التعارض في الأسماء تلقائياً.
  - **نظام التراجع الآمن (`--revert`):** إمكانية استعادة الأسماء القديمة بنقرة واحدة عبر `rename_rollback.json`.

- 🗂️ **إعادة الهيكلة والتصنيف الفرعي (`organize_subcategories.py`):**
  - تجزئة الأقسام الضخمة (مثل قسم التصوف) إلى مجلدات موضوعية متخصصة.
  - تجميع السلاسل الرواية والتصنيفات بحسب أرقام الأجزاء.

- 🏷️ **استخراج البيانات الوصفية والوسوم الذكية (`generate_catalog.py`):**
  - استخراج عنوان الكتاب الأصلي والمؤلف الحقيقي من داخل ملفات الـ PDF والـ EPUB (`PyMuPDF`).
  - تطبيق خوارزمية **الوسوم الذكية (Smart Tags)** لتصنيف الكتب موضوعياً (`#إدارة_ومال`, `#تصوف_وروحانيات`, `#طب_وأعشاب`, `#فلسفة_وفكر`, إلخ).

- 🌐 **لوحة تحكم تفاعلية متقدمة (`index.html` Dashboard):**
  - **بحث فوري:** بحث لحظي بالعنوان، اسم المؤلف، الوسام، أو القسم.
  - **رسوم بيانية إحصائية:** رسم بياني (SVG) يُظهر توزيع أحجام الأقسام المئوية.
  - **مُتتبع حالة القراءة (Reading Status):** إمكانية تحديد حالة كل كتاب (`لم يبدأ 📥` | `قيد القراءة 📖` | `تمت القراءة ✅`) والمزامنة محلياً بـ `localStorage`.
  - **فلاتر متعددة:** تصفية فورية حسب الصيغة، حالة القراءة، والوسوم.

- ☁️ **استضافة مجانية على GitHub Pages:**
  - نشر وتحديث تلقائي على رابط الويب الخاص بالمكتبة.

- 🔄 **تزامن تلقائي مع الهاتف:**
  - دليل إعداد عملي باللغة العربية (`SYNCTHING_GUIDE.md`) لربط المكتبة بتطبيق **ReadEra** عبر **Syncthing**.

## 🚀 طريقة الاستخدام

### 1. إزالة الكتب المكررة

```bash
# معاينة الكتب المكررة قبل الحذف (Dry Run)
python3 deduplicate_books.py

# تطبيق إزالة وحذف النسخ المكررة فعلياً
python3 deduplicate_books.py --commit
```

### 2. تنظيف أسماء الكتب

```bash
# معاينة التعديلات بدون تطبيق (Dry Run)
python3 clean_filenames.py

# تطبيق تنظيف الأسماء فعلياً
python3 clean_filenames.py --commit

# التراجع عن التعديلات الأخيرة وإعادة الأسماء القديمة
python3 clean_filenames.py --revert
```

### 3. تحديث الفهرس ولوحة التحكم

```bash
python3 generate_catalog.py
```

## 🛠️ أدوات المشروع

- `deduplicate_books.py`: سكربت فحص وإزالة النسخ المكررة مطابقة المحتوى.
- `clean_filenames.py`: سكربت تنظيف وتعديل أسماء الملفات.
- `organize_subcategories.py`: سكربت التقسيم المتقدم للأقسام الضخمة.
- `generate_catalog.py`: مولد البيانات والوسوم والفهارس.
- `index.html`: لوحة التحكم والتحليلات التفاعلية.
- `SYNCTHING_GUIDE.md`: دليل التزامن التلقائي مع الهاتف.
